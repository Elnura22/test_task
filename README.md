описание: REST API сервис для управления динамическими таблицами(создание схем, получение схем по имени, получении информации о таблицах) и также crud(создания, редактирования, удаления записей).

Java, Spring Boot, Spring data Jpa, sql, Postgres, Maven. библиотеки: hibernate, lombok, jakarta validation.

создала базу, заранала контейнер на порту 8085, указала все настройки в app.properties, для тестирования использовала Postman

все таблицы в схеме public, id автоматически создаются, валидация на всех реквестах, column.type это энам, для инсертов и работы с таблицами используется jdbcTemplate, есть глобальный обработчик ошибок для стандартизированного json response.
